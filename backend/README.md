# 뉴리의창고 백엔드 설치 (구글 앱스 스크립트)

댓글, 좋아요, 뉴리펫 쪽지 메일을 처리하는 작은 백엔드예요.
데이터는 내 구글 시트에 쌓이고, 알림 메일은 내 Gmail 에서 나에게 보내져요. 비용은 없어요.

## 1. 시트 만들기

1. <https://sheets.new> 를 열어 새 스프레드시트를 만들고 이름을 `뉴리의창고 댓글` 로 바꿔요.
2. 메뉴에서 **확장 프로그램 → Apps Script** 를 눌러요.

## 2. 코드 붙여 넣기

1. 열린 편집기의 `Code.gs` 내용을 모두 지우고, 이 폴더의 `Code.gs` 를 통째로 붙여 넣어요.
2. 디스크 모양 **저장** 버튼을 눌러요.

## 3. 처음 한 번 실행 (`setup`)

1. 위쪽 함수 선택 칸에서 `setup` 을 고르고 **실행** 을 눌러요.
2. "권한 검토" 창이 뜨면 내 구글 계정을 고르고 허용해요.
   - "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (안전하지 않음)으로 이동** 을 눌러요.
     내가 방금 만든 스크립트라서 나오는 경고예요.
3. 끝나면 시트에 `comments`, `likers` 탭이 생기고, **주인 모드 링크** 가 메일로 와요.
   이 링크를 내 브라우저에서 한 번 열면, 그 브라우저에서 남기는 댓글은 "뉴리" 로 표시돼요.
   링크는 다른 사람에게 보내지 마세요.

## 4. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포** 를 눌러요.
2. 톱니바퀴에서 유형 **웹 앱** 을 고르고 이렇게 설정해요.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
3. **배포** 를 누르고, 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`) 을 복사해요.

## 5. 사이트에 연결

`quartz/static/nyuri-config.js` 의 `api` 에 웹 앱 URL 을 넣고 푸시하면 끝이에요.

```js
window.NYURI = {
  api: "https://script.google.com/macros/s/여기에_복사한_ID/exec",
  site: "https://imvely.github.io/nyuri-garden/",
}
```

## 코드를 고친 뒤에는

편집기에서 저장한 다음 **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포** 를 눌러야 반영돼요.
URL 은 그대로예요.

## 알아 두기

- 비밀번호는 소금을 친 SHA-256 해시로만 저장돼서, 시트를 열어도 원래 비밀번호는 보이지 않아요.
- 댓글을 지우거나 고치고 싶으면 시트에서 직접 해도 돼요. `deleted` 를 `TRUE` 로 바꾸면 "삭제된 댓글이에요" 로 보여요.
- Gmail 무료 계정은 하루 약 100통까지 메일을 보낼 수 있어요.
- 너무 많은 요청을 막으려고 1분에 댓글 20개, 쪽지 10개까지만 받아요.

## 방문 분석과 한꺼번에 세기 (2026-11-07 추가)

`Code.gs` 에 두 기능이 더해졌어요.

- `counts`: 여러 글의 좋아요, 댓글 수를 한 번에 줘요. 카테고리 목록과 '다음에 읽을 글'이 써요(5분 캐시).
- `track`: 방문 기록을 `views` 탭에 쌓아요. IP 와 브라우저 정보는 받지 않고, 주인 모드 링크를 연 브라우저의 방문은 세지 않아요.

반영하는 방법

1. Apps Script 편집기의 `Code.gs` 를 이 폴더의 새 `Code.gs` 로 통째로 바꾸고 저장해요.
2. 함수 선택 칸에서 `setupAnalytics` 를 골라 한 번 실행해요. `views` 탭과 `대시보드` 탭이 생겨요.
3. **배포 → 배포 관리 → 연필 아이콘 → 버전: 새 버전 → 배포** 를 눌러요. URL 은 그대로예요.

`대시보드` 탭에서 최근 30일 조회와 방문자, 글별 조회, 유입 경로(검색, AI 답변, 커뮤니티, SNS, 직접, 사이트 안), 외부 사이트, 글별 평균 스크롤과 읽은 시간, '다음에 읽을 글' 클릭, 기기 비율을 볼 수 있어요.
새 버전을 배포하기 전에도 사이트는 그대로 동작해요(목록은 글마다 세는 예전 방식으로, 방문 기록은 쌓이지 않음).
